HIPOPOTAMPRO — WEB SITE STARTER

Açmak:
1) ZIP dosyasını bilgisayarınıza çıkarın.
2) index.html dosyasına çift tıklayın.
3) Site tarayıcıda açılır.

Yayınlamak:
- Hosting hesabınızın public_html klasörüne index.html, style.css ve script.js dosyalarını yükleyin.
- Kendi alan adınızı hosting panelinden bağlayın.

Düzenleme:
- Site metinleri index.html içindedir.
- Renkler ve görünüm style.css içindedir.
- Menü davranışı script.js içindedir.
- Görseller internet bağlantısıyla Unsplash üzerinden yüklenir; örnek görsellerdir.
- hello@hipopotampro.com adresini kendi e-posta adresinizle değiştirin.
